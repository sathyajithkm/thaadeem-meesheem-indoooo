### Project Description
Beard-O-Meter is a completely unnecessary AI-powered facial-hair analyzer that examines a person's face and estimates their current beard and moustache status. It also gives a hilariously unreliable prediction of future beard and moustache growth.

The project detects facial regions using MediaPipe Face Landmarker, calculates approximate facial-hair density, estimates the current number of hairs, and generates ridiculous future predictions such as beard "loading time."

### The Problem (that doesn't exist)
Millions of people wake up every morning wondering:

"Will I grow a beard in the future?" 🧔

Unfortunately, there is no urgent technology capable of answering this extremely important question with completely unnecessary precision.

People also need answers to other critical questions:

How many beard hairs do I currently have?
How strong is my moustache?
How much beard potential do I have?
When exactly will my beard finish downloading?
Is my beard stuck at 37%?
Has my moustache contacted the Beard Council yet?

Beard-O-Meter exists to solve this completely fictional crisis.

### The Solution (that nobody asked for)
We created Beard-O-Meter, a web application that analyzes an uploaded face and produces an entertaining facial-hair report.

The system:

Accepts a user's photograph.
Detects the face using MediaPipe.
Identifies the moustache and beard regions.
Calculates approximate hair density.
Estimates current beard and moustache hair counts.
Generates beard and moustache growth potential.
Generates a completely random beard loading time.
Displays the results in a colorful and entertaining interface.

The future prediction is intentionally not scientifically valid and is purely for entertainment. 😂

### Implementation
Create and activate a Python virtual environment:

python -m venv venv312

Activate it:

venv312\Scripts\activate

Install the required libraries:

pip install flask opencv-python mediapipe numpy werkzeug

The MediaPipe face landmark model should be placed at:

models/face_landmarker.task

# Run
Start the Flask application:

python app.py

Then open:

http://127.0.0.1:5000

Upload a photograph and let the Beard-O-Meter perform its extremely important analysis.
